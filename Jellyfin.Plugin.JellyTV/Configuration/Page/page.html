Catálogo de proveedores FAST

            
Canales gratuitos de Pluto TV, Plex y Tubi, consultados directamente en cada proveedor. Abre un proveedor, marca los canales que quieres y pulsa «Importar»: el canal se crea con su logo y su id de guía, y la guía del proveedor se añade a las fuentes EPG (sincronízala después). Muchos canales están en varios proveedores: te avisamos cuando ya tienes uno con el mismo nombre.

            

              
              
              
El catálogo lo decide el país de la IP. Con un proxy de otro país (pestaña Proxies) ves el catálogo de ese país, y los canales que importes salen por ese mismo proxy.

            

            

          

        


        

          

            
Fuentes EPG (XMLTV)

            
El plugin descarga tus fuentes XMLTV, filtra solo tus canales (por tvg-id o, si la fuente no lo trae, por nombre), enriquece con TMDB y fusiona una guía local que Jellyfin consume automáticamente.

Proxies de salida

                
Para canales con geobloqueo. Declara el país por el que sale cada proxy y, en la fuente del canal, elige ese país en «Salida»: el servidor descarga el canal completo (lista, variantes y segmentos) por un proxy de ese país, siempre el mismo para no cambiar de IP a media transmisión. Si falla, pasa a otro del mismo país.

Tuner y entrega

            

              
              
              
El tuner M3U estándar de Jellyfin 12 nunca reproduce en directo un manifiesto .m3u8 y fuerza el transcode; el servicio nativo sí permite Direct Play.

            

            

            

              Tuner M3U
              
              
            

            
No hace falta: cada cliente recibe el relay con el mismo host con el que abrió Jellyfin (localhost, red local o dominio público). Solo se usa en tareas sin cliente, como refrescar la guía.

            

          


          

            
TMDB

            
Con una credencial TMDB el plugin enriquece la guía local con arte y metadata de los programas. Sin ella se usa el contenido original de las fuentes.

            

          


          

            
Guía automática

            
Los canales se identifican en iptv-org (país, tvg-id y logo). Con eso el plugin descarga solo los XMLTV públicos de los países de tus canales y reparte la programación a cada uno; a los que ninguno cubre les busca su página en GatoTV. Lo que añadas abajo o en la ficha del canal tiene prioridad. Desactívala si prefieres usar únicamente tus fuentes.

            

          


          

            
Recetas de guías HTML (avanzado)

            
Cuando la guía propia de un canal es una página web (no un JSON ni un XMLTV), el plugin la lee con una receta: datos que dicen cómo reconocer cada fila de la programación. Ya viene incluida la de gatotv.com (páginas de canal); aquí puedes añadir otras como una lista JSON. Cada receta lleva host (dominio), row (expresión regular con los grupos start, title y, si existen, stop, desc, image), zone (zona IANA de las horas), dayUrl (por ejemplo {url}/{date:yyyy-MM-dd}), days y delayMs. Usa Probar guía en la ficha del canal para comprobarla antes de guardar.

            

          


          

            
Zona horaria de la guía

            
Zona IANA en la que están escritas las horas de tus XMLTV. Pulsa Usar mi zona para tomar la del navegador. Déjalo en UTC si tu archivo ya viene en UTC.

Almacenamiento

            
Dónde se guardan canales, proxies y fuentes EPG. PostgreSQL requiere el plugin PostgreSQL Database Provider y que Jellyfin use PostgreSQL; si no está disponible, el plugin usa archivos JSON locales sin obligarte a instalar nada.

            

              
              
              
El cambio se aplica al reiniciar Jellyfin. La configuración XML se mantiene como espejo para que el cambio sea reversible.

            

            

              
              
Solo se acepta una ruta absoluta. Si está vacía, se usa la carpeta de datos del plugin, que sobrevive a las actualizaciones.

            

            

              

            

            
La copia JSON te deja migrar o volver a archivos sin depender de PG Provider.

Fuentes / transmisiones

              

              

                
              

              
La primera fuente es la principal; el resto son respaldos en orden.
Directo: URL reproducible tal cual, Jellyfin la reproduce sin pasar por el plugin. FAST: canal público sin token; el plugin lo sirve por su relay y limpia anuncios y beacons. Tokenizado: la URL es un gateway que entrega un token. Sin marcar Token de sesión el token es efímero y lo renueva el plugin; marcado, el token dura horas y se entrega directo.
